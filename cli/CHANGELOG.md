# Changelog

All notable changes to the Gentoro MCP Agent CLI will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-10-30

### Added
- Initial release of MCP Agent CLI
- Interactive setup wizard for first-time users
- Support for OpenAI, Google Gemini, and Anthropic Claude providers
- Mock mode with built-in Acme Analytics server
- Service management (start, stop, status, restart)
- Configuration management system
- Authentication and token renewal
- Interactive chat mode
- Handbook management commands (init, validate, list)
- Provider switching capabilities
- Comprehensive logging and diagnostics
- Doctor command for system health checks
- Installation script for easy deployment

### Features
- Process management for all MCP Agent services
- Health checks for all running services
- Automatic service dependency management
- Log viewing and archiving
- Handbook directory structure creation
- Service authentication configuration
- Token expiration handling
- Multiple handbook support
- Configuration validation

### Documentation
- Complete CLI documentation
- Installation guide
- Usage examples
- Configuration reference
- Troubleshooting guide
